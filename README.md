## 🚀 Quick Start / How to Run

Because ASTROJYOTISH PRO is built as a single, self-contained HTML application:

### Method 1: Local Double-Click (Zero Setup)
1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/astrojyotish-pro.git
   cd astrojyotish-pro
   ```
2. Double-click `index.html` to open it in Google Chrome, Safari, Edge, or Firefox.
3. Everything works immediately!

### Method 2: Deploy Free on GitHub Pages (1-Click)
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages** in your repository.
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**.
5. Your professional astrology web app is live on `https://<your-username>.github.io/<repo-name>/`!

## 🤖 Importing into Google AI Studio (Gemini Studio)

See [`gemini_studio/GEMINI_STUDIO_IMPORT_GUIDE.md`](gemini_studio/GEMINI_STUDIO_IMPORT_GUIDE.md) for full instructions:

1. **In-App**: Simply paste your Gemini API key directly into the **🤖 జెమిని AI ఆస్ట్రాలజర్** panel in `index.html`.
2. **In Google AI Studio**:
   - Open [aistudio.google.com](https://aistudio.google.com).
   - Create a new prompt and set the System Instructions using [`gemini_studio/gemini_system_prompt.txt`](gemini_studio/gemini_system_prompt.txt).
   - Optionally add function calling tools from [`gemini_studio/gemini_function_declarations.json`](gemini_studio/gemini_function_declarations.json).
   - Test using [`gemini_studio/sample_chart_context.json`](gemini_studio/sample_chart_context.json).
